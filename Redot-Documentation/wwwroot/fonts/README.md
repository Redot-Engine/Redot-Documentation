# Bundled webfonts

The site serves these unmodified variable WOFF2 fonts locally, with normal and
italic faces. Each font's original SIL Open Font License 1.1 notice is bundled
alongside its font files and linked from `/licenses`.

## Geist

- Source: <https://github.com/vercel/geist-font>
- Revision: `10dc7658f13c38a474cde201bb09a4617267545b`
- Upstream files: `fonts/Geist/webfonts/Geist[wght].woff2` and
  `fonts/Geist/webfonts/Geist-Italic[wght].woff2`
- Local filenames: `geist/Geist-Variable.woff2` and
  `geist/Geist-VariableItalic.woff2`
- License: upstream `OFL.txt`, copied to `geist/OFL.txt`
